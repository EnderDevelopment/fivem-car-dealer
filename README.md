# FiveM Car Dealer

Easy-to-use car dealer script for FiveM servers

## Features

- Configurable dealer location and appearance
- List of available cars with prices
- User-friendly interface for buying and spawning cars

## Requirements

- FiveM server
- ESX Framework
- MySQL database

## Installation

1. Download the script files
2. Place them in your FiveM server's resources folder
3. Import the database.sql file into your MySQL database
4. Add `start cardealer` to your server.cfg file

## Usage

1. Players can approach the dealer location to open the car dealer menu
2. Players can select a car from the list and buy it if they have enough money
3. The purchased car will spawn in front of the player

## Configuration

The script can be configured in the config.lua file. You can change the dealer location, appearance, and the list of available cars with their prices.
